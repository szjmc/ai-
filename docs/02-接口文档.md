## 1. POST /api/v1/file/uploadFile

上传文件。`multipart/form-data`。

**表单字段**

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file` | ✅ | 文件本体，≤ 50MB |
| `collection_name` | ✅ | 集合名称，1–256 字符 |
| `description` | | 描述，≤ 255 字符 |
| `chunk_strategy` | | `adaptive`(默认)/`fixed`/`semantic`/`recursive`/`paragraph` |
| `created_by` | | 创建者 ID，默认 1 |

**请求**

```bash
curl -X POST http://127.0.0.1:3000/api/v1/file/uploadFile \
  -F "file=@doc-demo.md;type=text/markdown" \
  -F "collection_name=开发文档样例" \
  -F "description=接口样例" \
  -F "chunk_strategy=adaptive" \
  -F "created_by=1"
```

**响应 `HTTP 201`**

```json
{
    "status": 200,
    "message": "文件上传成功",
    "data": {
        "id": "afff4563-8669-44da-886e-b5171e6838e4",
        "collection_name": "开发文档样例",
        "file_name": "doc-demo_036a8876.md",
        "file_type": "md",
        "minio_path": "knowledge-base/doc-demo_036a8876.md",
        "chunk_strategy": "adaptive",
        "description": "接口样例",
        "status": "uploaded",
        "created_time": "2026-10-27T03:22:31.321Z",
        "updated_time": "2026-10-27T03:22:31.321Z",
        "created_by": 1,
        "updated_by": 0,
        "version_no": 1,
        "original_name": "doc-demo.md",
        "file_size": 34,
        "content_type": "text/markdown",
        "file_url": "/api/v1/file/afff4563-8669-44da-886e-b5171e6838e4/download"
    },
```

## 4–6. 单条记录 `/api/v1/file/{id}`

### GET — 详情
返回与列表项结构相同的单个 `FileDict`。

### PATCH — 改元数据

**请求体**（全部可选，只传要改的）

```json
{
  "collection_name": "数据字典",
  "description": "补充说明",
  "status": "active",
  "chunk_strategy": "semantic",
  "updated_by": 2
}
```

**响应 `HTTP 200`**：`message: "知识文件已更新"`，`data` 为更新后的 `FileDict`（`version_no` 已 +1）。

> 后端用增量 SQL，只更新传入的字段：
> ```ts
> const sets: SQL[] = [sql`version_no = COALESCE(version_no, 0) + 1`, sql`updated_time = ${new Date()}`];
> if (patch.collectionName !== undefined) sets.push(sql`collection_name = ${patch.collectionName}`);
> if (patch.updatedBy !== undefined) sets.push(sql`updated_by = ${patch.updatedBy}`);
> await db.execute(sql`UPDATE knowledge_files SET ${sql.join(sets, sql`, `)} WHERE id = ${id}`);
> ```

### DELETE — 删除
同时删除 MinIO 对象与数据库记录。响应 `{"status":200,"message":"文件已删除","data":{"id":"..."}}`。

## 8. PUT /api/v1/file/{id}/content — 在线改正文

**请求**

```bash
curl -X PUT http://127.0.0.1:3000/api/v1/file/{id}/content \
  -H 'Content-Type: application/json' \
  -d '{"content":"# 修改后标题\n\n这是改过的正文。","updated_by":2}'
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `content` | ✅ | 新正文全文（UTF-8），≤ 50MB |
| `updated_by` | | 操作人 ID |
| `description` | | 同时更新描述 |

**响应 `HTTP 200`**（字段已裁剪展示）

```json
{
  "status": 200,
  "message": "文件内容已更新",
  "data": {
    "id": "afff4563-8669-44da-886e-b5171e6838e4",
    "version_no": 2,
    "updated_by": 2,
    "file_size": 43,
    "updated_time": "2026-10-27T03:22:31.418Z"
  }
}
```

> 注意 `version_no` 从 1 → 2，`file_size` 从 34 → 43，与新正文字节数一致。

## 10. GET /api/v1/file/{id}/preview — 预览数据

**查询参数**：`sheet`（可选，仅 XLSX，指定工作表名）

`kind` 共 6 种，前端据此选择渲染器：

| kind | 触发类型 | 关键字段 |
| --- | --- | --- |
| `text` | txt/md/json/sql | `text`、`truncated`（上限 20 万字） |
| `image` | png/jpg/jpeg/webp/gif | 无正文，前端另取 blob |
| `pdf` | pdf | 无正文，前端另取 blob |
| `document` | docx | `document_html`、`warnings` |
| `spreadsheet` | xlsx/xls | `sheet_names`、`active_sheet`、`table` |
| `binary` | doc/xls 等不可渲染 | 仅提示下载 |

**DOCX 真实样本**（37 张图的大文档）

```json
{
  "kind": "document",
  "truncated": false,
  "content_type": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
  "warnings": [],
  "document_html_长度": 135773,
  "img标签数": 37,
  "document_html_片段": "<h1><strong>大模型开发之LangChain</strong></h1><p>官网：https://www.langchain.com/</p>…"
}
```

> 图片**不内联 base64**，`<img src>` 指向接口 12。该文档内联时曾达 9.4MB，现在仅 136KB。

**XLSX 真实样本**（指定工作表）

```json
{
  "kind": "spreadsheet",
  "sheet_names": ["营养筛查-BMI计算公式","营养筛查-营养状态受损评分","营养筛查-疾病严重程序评分","营养筛查-年龄评分","营养筛查-NRS2002评分"],
  "active_sheet": "营养筛查-年龄评分",
  "table": {
    "columns": ["A","B","C","D","E","F"],
    "row_numbers前5": [1,2,3,4,5],
    "rows前3": [
      ["序号","是否住院","年龄","评分","评分公式","备注"],
      ["1","1","70","1","年龄>=70 and 是否住院=1",""],
      ["20","1","18","0","年龄<70 and 是否住院=1",""]
    ],
    "merges": [],
    "total_rows": 55,
    "total_columns": 6,
    "truncated": false
  }
}
```

> `columns` / `row_numbers` 是 Excel 里的**真实列字母和行号**，隐藏行列不出现在数组中。

## 11. GET /api/v1/file/{id}/download — 下载

**查询参数**：`disposition=inline`（预览用，仅对 PDF/图片/文本生效）

支持 HTTP Range，PDF 分段加载依赖此能力：

```bash
curl -D - -H 'Range: bytes=0-99' http://127.0.0.1:3000/api/v1/file/{id}/download
```

```
HTTP/1.1 206 Partial Content
accept-ranges: bytes
content-range: bytes 0-99/63275
content-length: 100
content-disposition: attachment; filename="____-BMI.xlsx"; filename*=UTF-8''%E8%90%A5%E5%85%BB%E7%AD%9B%E6%9F%A5-BMI.xlsx
```

> 中文名用 RFC 5987 的 `filename*` 传递，ASCII `filename` 作为老浏览器回退。

## 13. /api/operators — 操作人目录

### GET

```json
{
    "status": 200,
    "message": "success",
    "data": [
        { "id": 1, "name": "林知衡", "role": "知识库管理员" },
```

## 16. POST /api/v1/chunks/parseFile — 文档分片

**纯透传接口**：Next.js 不做任何分词、向量化或 Milvus 操作，只把请求体原样转发给
FastAPI `POST {FASTAPI_URL}/api/v1/chunks/parseFile`，再把结果包回统一信封。

**请求体**（字段由后端 `process_minio_document` 定义）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file_id` | ✅ | 记录 ID，用于生成 `chunk_id` 前缀 |
| `minio_path` | ✅ | MinIO 对象路径 |
| `file_name` | | 存储名，后端 `_extract_object_name` 优先用它作为下载对象名 |

```bash
curl -X POST http://127.0.0.1:3000/api/v1/chunks/parseFile \
  -H 'Content-Type: application/json' \
  -d '{"file_id":"afff4563-…","minio_path":"knowledge-base/doc_036a8876.md","file_name":"doc_036a8876.md"}'
```

**响应 `HTTP 200`**（`data` 为 FastAPI 原样返回）

```json
{
  "status": 200,
  "message": "text splitter successfully",
  "data": {
    "file_id": "afff4563-…",
    "file_name": "doc_036a8876.md",
    "minio_path": "knowledge-base/doc_036a8876.md",
    "chunks_processed": 7,
    "chunk_ids": [101, 102, 103, 104, 105, 106, 107],
    "process_time": "2026-10-27T05:30:00.123456"
  },
  "page": null
}
```

**错误映射**（代理层翻译，便于定位问题）

| 情况 | 返回 | 说明 |
| --- | --- | --- |
| FastAPI 未启动 | 503 | `无法连接解析服务 … 请确认 FastAPI 已启动` |
| 上游 500 | 502 | `chunk_router.parse_file` 吞掉异常后返回 None，FastAPI 校验 `response_model` 失败回 500。提示检查 Ollama / Milvus / MinIO 与后端日志 |
| 上游 200 但 `data` 为空 | 502 | `解析服务未返回结果数据，请查看 FastAPI 控制台日志` |
| 超过 10 分钟 | 504 | 提示任务可能仍在后端运行，不要立即重复提交 |
| 缺 `file_id` / `minio_path` | 400 | 代理层前置校验，给出比 500 更明确的信息 |

## 18. POST /api/v1/chat/systemRagQuery — NRS2002 智能问答

**纯透传**：转发给 FastAPI `POST {FASTAPI_URL}/api/v1/chat/systemRagQuery`，不做任何检索或 LLM 逻辑。

**请求体**（对应后端 `UserQueryRequest`）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `question` | ✅ | 患者信息描述 |
| `file_id` | ✅ | 关联的知识文件 ID，须已在 Milvus 中分片 |
| `collection_name` | ✅ | **Milvus 集合名**（不是 MySQL 的 collection_name） |
| `top_k` | | 检索片段数，默认 2 |

```bash
curl -X POST http://127.0.0.1:3000/api/v1/chat/systemRagQuery \
  -H 'Content-Type: application/json' \
  -d '{"question":"患者女性，65岁，BMI 19.2，2型糖尿病稳定期，近3个月体重下降4.6%","file_id":"<id>","collection_name":"yycp","top_k":2}'
```

**响应 `HTTP 200`**（`data` 为后端原样返回）

```json
{
  "status": 200,
  "message": "NRS2002评分查询成功",
  "data": {
    "score_info": {
      "score": 2, "nutritional_impairment": 1, "disease_severity": 1, "age": 0,
      "basis": "1.营养受损：BMI19.2（18.5-20.4）→1分；2.疾病严重度：糖尿病稳定期→1分；3.年龄65岁＜70→0分；总分1+1+0=2分"
    },
    "source_basis": [
      { "file_name": "NRS2002规则_1a2b3c4d.md", "file_id": "…", "rule_fragment": "BMI 18.5-20.4 → 营养状态受损 1 分", "retrieval_type": "vector" }
    ],
    "query_params": { "file_id": "…", "collection_name": "yycp", "top_k": 2, "query_time": "2026-10-27 21:40:00" }
  },
  "page": null
}
```

**错误映射**

| 情况 | 返回 | 说明 |
| --- | --- | --- |
| FastAPI 未启动 | 503 | 提示 `python main.py` |
| 上游 500 | 502 | 提示检查 Milvus 数据 / Ollama 模型 / LLM 输出 JSON |
| 200 但 `data` 为空 | 502 | 未返回结果数据 |
| 后端 404 | 404 | 透传，如 `指定file_id=xxx无匹配的NRS2002规则数据` |
| 超过 5 分钟 | 504 | 提示查看后端日志 |
| 缺 `question`/`file_id`/`collection_name` | 400 | 代理前置校验 |

## 20. POST /api/v1/chat/asr — 语音转文字

`multipart/form-data`，字段 `audio`（录音文件，≤ 20MB）。

前端统一在 `client-api.ts` 的 `readBody()` 中解析，把 `hint` 拼进错误信息：

```ts
async function readBody<T>(response: Response): Promise<ApiBody<T>> {
  const body = await response.json().catch(() => null) as ApiBody<T> | null;
  if (!body || typeof body.message !== "string") throw new Error(`请求失败（${response.status}），请稍后重试`);
  if (!response.ok || body.status >= 400) {
    const hint = body.data && typeof body.data === "object" && "hint" in body.data ? String(body.data.hint || "") : "";
    throw new Error(hint ? `${body.message}：${hint}` : body.message);
  }
  return body;
}
```
